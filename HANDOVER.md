## Go-live route A — GitHub Pages (recommended for this site)

Repo: https://github.com/Ann0nn/annon-portfolio

1. Open the repo → **Settings** → **Pages**.
2. Under "Build and deployment", choose **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`. Save.
4. Wait ~1–2 minutes. Your site appears at `https://ann0nn.github.io/annon-portfolio/`.
5. Custom domain later: buy the domain in your own name, add it under the same Pages settings, then add the DNS record GitHub shows you. Turn on **Enforce HTTPS** once it becomes available.

Note: the pushed copy is v1. The corrected WhatsApp number is in this delivery pack and in the local source — push the correction before enabling Pages, or Pages will show the old CV number in the WhatsApp links.

## Go-live route B — hosting / cPanel upload

1. Log in to the hosting panel for the domain.
2. Open File Manager → `public_html`.
3. Upload `index.html` (overwrite if asked).
4. Visit the domain — the site is live. Make sure the domain has an SSL certificate active (most hosts enable it free under "SSL/TLS Status" / AutoSSL).
