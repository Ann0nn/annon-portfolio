# Annon — Portfolio & Services Site

One-page website for Annon's web design and assistant-building services:
business websites, booking pages, and FAQ/sales assistants for businesses
that run on WhatsApp.

- `index.html` — the whole site (single file, no build step, no dependencies)
- Prices are intentionally not listed; every project is quoted individually
- All contact buttons deep-link to WhatsApp with a prefilled message

Deploy: any static host (Netlify, GitHub Pages, Vercel). On Netlify, connect
this repo and it redeploys automatically on every push — no build command,
publish directory is the repo root.
